# Dự án môn học Quản trị dự án CNTT `" Ứng dụng theo dõi thói quen "`

## Các diễn viên chính:

- ThS. Huỳnh Quang Đức: Giảng viên môn học
- Các thành viên trong nhóm:
  - `GOAT` Lý Lâm Vũ (23050102)
  - `Phó GOAT` Phạm Đức Nhân (23050104)
  - `Phó GOAT` NGuyễn Đức Long (23050079)
  - `COAT` Nguyễn Tuấn Anh (23050118)

## Sơ qua về dự án

- `Mục đích thực hiện dự án`: Cung cấp công cụ giúp người dùng theo dõi thói quen sinh hoạt hằng ngày, nhắc nhở những việc cần làm, từ đó giúp họ kiểm soát bản thân và duy trì kỷ luật tốt hơn.
- `Các mục tiêu của dự án`:
  - Xây dựng hệ thống:
    - Thiết kế CSDL với PostgreSQL và SQLalchemy
    - Thiết kế bộ RESTFul API với FastAPI (Python)
    - Tích hợp JWT cho phân quyền, bảo mật
  - Xây dựng giao diện
    - Xây dựng giao diện với React JS và Tailwind CSS
    - Hoàn thiện các giao diện: Dashboard, quản lý thói quen, profile, giao diện quản lý của Admin
  - Triển khai thực tế
    - Deploy ứng dụng lên Internet, Frontend ở Vercel, Backend ở Render, Database ở Supabase

- `Thời gian ước lượng cho dự án`: Dự án được triển khai từ 12/01/2026 và `dự kiến` hoàn thành vào 12/04/2026.
